Configuration d'un Switch réseau
TP_01 · Stage Inovie · 2024 · Réseau
// Objectif

Chez Inovie, j'ai configuré un switch manageable pour segmenter le réseau en VLANs distincts (Administration, Laboratoire, Informatique) afin d'améliorer la sécurité et les performances du réseau local.

// Topologie
// Étapes
1

Connexion console

Câble console RJ45→USB. PuTTY : 9600 bauds, 8 bits, sans parité, 1 stop bit.

2

Mode privilégié

switch> enable puis configure terminal.

3

Création des VLANs

VLAN 10 (Administration), VLAN 20 (Laboratoire), VLAN 30 (Informatique) avec leurs noms.

4

Ports access & trunk

Chaque port assigné à son VLAN. Port uplink vers le routeur en mode trunk (allowed vlan 10,20,30).

5

Vérification & sauvegarde

show vlan brief, show interfaces trunk, puis copy run start.

// Commandes Cisco IOS
CISCO IOS
# Créer les VLANs
switch(config)# vlan 10
switch(config-vlan)# name Administration
switch(config)# vlan 20
switch(config-vlan)# name Laboratoire

# Port access VLAN 10
switch(config)# interface FastEthernet 0/1
switch(config-if)# switchport mode access
switch(config-if)# switchport access vlan 10

# Port trunk
switch(config)# interface GigabitEthernet 0/1
switch(config-if)# switchport mode trunk
switch(config-if)# switchport trunk allowed vlan 10,20,30

switch# copy running-config startup-config

Vérification prérequis

// Objectif

Installer les roles AD DS et DNS sur Windows Server, puis promouvoir le serveur en controleur de domaine. Prerequis : nom reconnaissable (ex: SRV-DC), adresse IP fixe, le serveur doit etre son propre serveur DNS principal.

// Prerequis obligatoires
Nom du serveur
Nom reconnaissable
Ex: SRV-DC ou AD (pas A54frzaFER)
Adresse IP
IP fixe obligatoire
Ex: 192.168.1.1 / 255.255.255.0
DNS prefere
Lui-meme
Le serveur est son propre DNS
OS
Windows Server
2019 / 2022 Standard ou Datacenter
// Schema de l'infrastructure
// Etapes - Installation des roles AD DS et DNS
1

Ouvrir le Gestionnaire de serveur

Menu Demarrer > Gestionnaire de serveur (ou ServerManager.exe). Cliquer sur "Ajouter des roles et des fonctionnalites".

2

Type d'installation et serveur de destination

Cliquer Suivant. Selectionner "Installation basee sur un role ou une fonctionnalite" > Suivant. Selectionner le serveur dans le pool > Suivant.

3

Cocher le role AD DS

Dans la liste des roles, cocher "Services AD DS". Une fenetre propose d'installer les fonctionnalites requises > cliquer "Ajouter des fonctionnalites".

4

Cocher le role DNS

Dans la meme liste, cocher egalement "Serveur DNS" > cliquer "Ajouter des fonctionnalites". Les deux roles sont selectionnes > Suivant.

5

Fonctionnalites et informations

Ne rien modifier dans la fenetre des fonctionnalites > Suivant. Lire les infos sur AD DS > Suivant. Lire les infos sur DNS > Suivant.

6

Confirmation et installation

Cocher "Redemarrer automatiquement le serveur si necessaire" > cliquer Installer. Patienter quelques minutes.

7

Promouvoir en controleur de domaine

Une fois l'installation terminee, cliquer sur "Promouvoir ce serveur en controleur de domaine" (notification dans le gestionnaire de serveur).

8

Creer une nouvelle foret

Cocher "Ajouter une nouvelle foret". Saisir le nom complet du domaine avec son extension, ex: lycee.local ou neptunet.lan > Suivant.

9

Options du controleur de domaine

Laisser le niveau fonctionnel par defaut. Le 1er DC est obligatoirement Serveur DNS et Catalogue Global. Definir un mot de passe DSRM (restauration d'annuaire) > Suivant.

10

Options DNS, NetBIOS et chemins

Ignorer l'erreur DNS (normale, la zone n'est pas encore creee) > ne pas cocher la delegation > Suivant. Laisser le nom NetBIOS par defaut. Laisser les chemins d'acces par defaut (base AD, logs, SYSVOL) > Suivant.

11

Verification et installation finale

Verifier le recapitulatif > Suivant. Cliquer Installer. Le serveur redemarre automatiquement. A la reconnexion, l'ecran affiche le nom NetBIOS du domaine et le compte Administrateur.

// Commandes Cisco IOS
CISCO IOS
# Router-on-a-stick
Router(config)# interface GigabitEthernet0/0.10
Router(config-subif)# encapsulation dot1Q 10
Router(config-subif)# ip address 192.168.10.1 255.255.255.0

# DHCP
Router(config)# ip dhcp pool VLAN10
Router(dhcp-config)# network 192.168.10.0 255.255.255.0
Router(dhcp-config)# default-router 192.168.10.1

# ACL — Bloquer VLAN30 vers VLAN10
Router(config)# access-list 110 deny ip 192.168.30.0 0.0.0.255 192.168.10.0 0.0.0.255
Router(config)# access-list 110 permit ip any any

Créer SRV-HAPROXY

2

Configurer HAProxy

3

SRV-WEB-01 (Apache, fond bleu)

// Config HAProxy
HAPROXY.CFG
backend web_servers
    balance roundrobin
    option httpchk GET /
    http-check expect status 200
    server web01 192.168.100.2:80 check inter 2000 rise 2 fall 3
    server web02 192.168.100.3:80 check inter 2000 rise 2 fall 3

DHCP sous Debian 12 (Linux)
TP_09 · Scolaire · isc-dhcp-server + réservation MAC · VirtualBox
📄 Télécharger le tutoriel PDF →
// Étapes
1

Identifier les interfaces

ip -brief addr → INT_NAT (10.0.2.x) et INT_INTERNE (sans IP). Adapter 1 = Internal, Adapter 2 = NAT.

2

Configurer les interfaces réseau

nano /etc/network/interfaces → INT_NAT : inet dhcp. INT_INTERNE : inet static 192.168.50.1/24.

3

Installer & configurer isc-dhcp-server

apt install isc-dhcp-server. /etc/default/isc-dhcp-server : INTERFACESv4="INT_INTERNE". Configurer dhcpd.conf.

4

Tester & réserver une IP

Client : dhclient -v INT_INTERNE. Serveur : tail -n 50 /var/lib/dhcp/dhcpd.leases. Réservation MAC dans dhcpd.conf.

// Configuration dhcpd.conf
DHCPD.CONF
subnet 192.168.50.0 netmask 255.255.255.0 {
    range 192.168.50.100 192.168.50.200;
    # Pas de option routers → Internet via carte NAT
    option subnet-mask 255.255.255.0;
    option broadcast-address 192.168.50.255;
}

# Réservation par adresse MAC
host poste1 {
    hardware ethernet 08:00:27:aa:bb:cc;
    fixed-address 192.168.50.110;
}
